# QA project rules

You are working in a Playwright (TypeScript) end-to-end test project for a web shop.
The system under test is already running at http://localhost:3000 and you can reach it with curl or a browser.
Tests live in `tests/`. Run them with `npx playwright test`. Do not edit `playwright.config.ts`.
Finish only when the tests you wrote or changed pass when you run them. End with a short summary of what you changed.
